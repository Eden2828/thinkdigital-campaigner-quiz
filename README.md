# מבחן קמפיינר: Think Digital

מבחן ידע לקמפיינרים מתחילים: מתמטיקה של מדדים (CTR, CPM, CPC, CPA, ROAS), חשיפות מול ריץ', מבנה ומטרות קמפיין במטא, CBO/ABO, קהלים, פיקסל ומדידה, גוגל אדס, וקריאייטיב ואופטימיזציה.

- **המבחן:** https://eden2828.github.io/thinkdigital-campaigner-quiz/
- **לוח התוצאות (למנהל/ת):** https://eden2828.github.io/thinkdigital-campaigner-quiz/results.html

## איך זה עובד
1. שולחים לעובד/ת את הקישור למבחן.
2. בסוף המבחן מקבלים ציון, פירוט לפי נושא, הסברים לכל תשובה וקוד תוצאה חתום.
3. העובד/ת שולח/ת את הקוד בוואטסאפ, ואת/ה מדביק/ה אותו בלוח התוצאות.

## עריכת שאלות
כל השאלות נמצאות ב-`questions.js`. בשאלה אמריקאית, האפשרות הראשונה ברשימה היא הנכונה (בתצוגה הסדר מעורבב).
